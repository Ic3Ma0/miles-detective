# 并行只加在调查阶段，按来源家族分片

大型联网调查的墙钟时间主要耗在发现与核验上，但写作需要统一的声音，合并与证据判定需要全局视野。我们决定：并行只用于发现与核验；默认按来源家族切分（本人署名与发言、新闻与特稿、论坛与旧社区、机构记录、播客与视频、著作与出版），每个分片覆盖全时段；只有单个家族过大时才按年代二次切分。默认 3 个 worker，最多 4 个。写作、合并总卷与最终语义检查始终由协调者单线程完成。

按年代切分会让同一个跨越多个阶段的来源被重复检索，也会让每个分片重复做身份索引；按来源家族切分与现有的覆盖表结构一致，同一事件被多个家族报道属于正常冗余，交给事件台账去重即可。环境不支持委派时，按同一分片计划顺序执行，分片契约不变。
