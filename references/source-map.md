# 人物调查来源地图

这是检索路由，不是“所有平台都已访问”的声明。按时代、语言、地区、职业选择适用项；未查项保留在覆盖表。先用人物的确定身份查，再把新发现的标题、账号、事件和关联人加入队列。网站入口及可用性会变化，运行时核验。

## 围绕一生的处境展开搜索

先梳理成长、求学、初入社会、探索与失败、重大转折及后续变化；阶段按人物实际经历划分，不强套成功学弧线。对有材料的阶段追问：

- 他当时在什么地方、做什么工作或作品？具体生活与时代环境怎样限制或帮助他？
- 他当时公开说想要什么，真正采取了哪些行动，面对哪些可见选项和代价？
- 哪些人、组织或事件参与其中？同期参与者怎样描述，后来本人又怎样回忆？
- 一次决定之后具体发生了什么？“后来发生”是否真有证据支持“由此造成”？
- 哪些可核实的小细节能让读者看清这一段人生，例如一封信、一篇原帖、一次失败的产品演示、一次公开争论？

先做跨渠道发现，再沿相关人物、准确题名、旧网名、域名和时间继续深挖。单篇人物简介和热门事件报道不足以覆盖一生；同时保留本人内容与他者材料两条线。行业、校园、地方和旧社区资料常能补到成名前的处境，不因材料较少或不够戏剧化而跳过。

场景资料既可来自同期记录，也可来自标明归属的事后回忆；不为渲染场面寻找未经证实的轶闻。时代背景应有相应来源，并区分“当时社会普遍如此”和“这个人确实经历过”。写作中的关键空白回到查询队列，不能为顺畅而补写。

网页获取时同时检查正文和原始链接。原文、历史账号、附件或节目外链应保留锚文本、完整地址与上下文，进入有价值的线索队列；只提取纯文本可能丢失最重要的入口。相关候选未处理时，不把缺口一概归结为登录或存档能力不足。

## 查询的展开

设 P 为人物名，H 为已核实网名，O 为学校/机构，T 为作品或事件标题，Y 为某阶段年份。中文、繁体、外文变体分别查，不假定引擎自动覆盖。下面是起点，不要求机械执行每条。

```text
"P" "O" Y
"P" 博客 / 个人网站 / 访谈 / 播客 / 演讲
"P" 曾用名 / 网名 / 人人 / 校内 / BBS
"P异体"            # 姓名异体、同音形近字、语音转录错字分别查
"H"                # 去掉姓名限制，可找只有账号的早期引用
"H" -site:已知重复站点
"T"               # 准确标题通常比姓名有效
"T" 回应 / 声明 / 更正 / 编辑 / 附件
"P" site:news.学校域名
"P" site:groups.google.com
"P外文名" interview / podcast / transcript / AMA
"P" "O" before:2015 after:2009
"旧域名/路径"      # 找别人留下的死链及引用
"ISBN" / "案号" / "项目稳定ID"
```

日期操作符通常筛索引时间，不能当作发表日证据。一个引擎无结果后，判断是否换语言、准确标题、站内检索或另一可用索引；不要不断换形容词搜同一类新闻。

对长尾线索可画成：**姓名 → 旧网名 → 转推备份 → 博客日期页 → 原帖 ID**，或 **报道 → 刊物名 → 公开邮件组 → 声明 → 附件 → 早期刊物**。每一跳都应记录前一条依据；未知身份关联留作候选。

## 旧站与存档支线

用户未暂停且需要历史恢复时，再展开这一段：

1. 从旧链接、签名或引用确定域名和路径，记录已知有效年代；不要凭网名创造一个“已确认旧站”。
2. 在 [Wayback](https://web.archive.org/) 按精确 URL/前缀查快照，兼查有依据的 http/https、www、移动域名。先看快照索引，再取具体内容。目录可能存了而单篇没存。
3. 可用 [Common Crawl 索引](https://index.commoncrawl.org/) 查 URL 的抓取记录；有索引再判断公开存储内容能否读取。不要把索引数量算作文章数量。
4. 档案不通时查原站 RSS、站点地图、公开镜像、引文、转载和机构保存版本；为每个保存版本单独记录载体与完整性。
5. 把“没快照”“索引接口失败”“有快照但正文失败”“原站登录限制”“本轮没查”分开。不因读取失败写成被删除；不保证存档覆盖已删除内容。

## 人物职业适配

渠道之外，还要按研究问题检查空白：著作里有哪些系统主张；长对话中面对追问怎样回答；短表达在不同时期如何变化；他人有哪些亲历与反对意见；重大决定的条件、行动及结果是什么；各阶段与最近一年的公开记录是否连得上。这六类问题借鉴女娲的研究分工，但不要求固定代理数量，也不预设最终必须提炼人格模型。

- 企业家：作品/账号之外，强化学校及职业早期、产品/公司沿革、融资披露、团队及伙伴公开记录、监管争议。
- 学者/工程师：论文、合著关系、实验室、会议录像、项目 issue 与版本史；不把同名论文直接归人。
- 作者/艺术家：初刊、作品版本、编辑往来公开记录、访谈、展演目录与评论；区分本人叙述、作品中的虚构人物和事实。
- 其他人物按其真实活动增减；不能把“币圈媒体”作为所有中国企业家的默认渠道。
