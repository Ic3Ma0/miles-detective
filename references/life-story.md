# 以证据写出有现场感的人生故事

用于广泛人物调查后的主故事写作与审稿。最终阅读体验应使读者进入人物当时的处境，沿行动与变化理解一生；来源与调查记录继续支撑所有细节。

## 先建立经历，再选择写法

整理已读材料中的时间、地点、在场者、行动、作品、公开说法、他者回应与后果，为关键内容保留来源和位置。把“当时说过”和“多年后如此回忆”分开。材料里的可疑引语、乱码或同名归属先核验，不能在写作时悄悄修成事实。

据此找到对人生有解释力的阶段与转折：什么处境持续困住他，他做了什么尝试，哪些事情未如预期，后续道路怎样变化。失败、停滞、日常积累和反复同样重要。不能预设此人必然成功、必然堕落或一生只有一种性格。

选开场时，优先考虑有足够细节、能让读者理解其处境的真实时刻；可以从人生中段切入再回溯，也可以顺叙，不固定结构。缺乏场景证据时，用具体行动和明确时间推进，不编一段开场。

## 让读者知道“他当时多大”

人物第一次出现时交代出生日期，至少给到年月；能确认到日就写到日。读者要靠这个日期自己换算，后文出现 1999 年、2019 年、2024 年时才不会疑惑年龄为什么忽大忽小。出生日期若只有二手来源，在附卷标明来源与可信程度；正文可以用它做年龄锚点，但不要把推算说成原件记载。出生日期无法确认时，写已知年份或大致年代，并在附卷说明缺口，不要为了年龄锚点编一个日期。

每个重要阶段的开头，用叙事自然带出年龄：“25 岁那年，他……”，“30 岁时，他第一次……”。不要把年龄做成表格，也不要每句都加“（时年 X 岁）”；读者需要在阶段入口知道大概多大，而不是每个日期都标数字。

日期精确到日、且已过生日时用实岁；只有年份或月份时写“约 X 岁”或“二十出头”，不假装精确。同一年里，生日前后的年龄会差一岁；开头已经交代出生日期，后文按生日换算即可，必要时用“过了生日，他 X 岁”自然说明。附卷时间线加年龄列并注明精度，正文只保留对理解转折有用的年龄锚点。

这样写不是给人物贴年龄标签，而是让读者能把“我当时这个年龄在做什么”放进他的处境。

## 姓名与公开身份

首次出现给全名或本名，再说明公开名、艺名或笔名。读者可能只熟悉公开名，所以可以先给公开名，紧接着给本名；但不要只用一个名字贯穿全文。本名不公开或无法确认时，说明公开名和已知身份，不要编一个本名。例如：先给读者熟悉的公开名，紧接着写“本名……”，读者就知道两个名字指同一个人；反过来也可以。姓名写法按原始页面，不自行统一异体字；有争议时在附卷保留。

多语种姓名、民族名、旧名、网名和账号名放附卷姓名索引，正文只在有叙事意义时出现。不要在开头堆一排别名，也不要把艺名当成唯一身份，让读者不知道这个人本名是什么。

## 重大转折要写出完整链条

先找出真正改变人生方向的事件，通常两到四个；不是所有困难都是转折，材料只支持一个就写一个，不为凑数把普通困难升级为转折。对每个转折，在“处境—行动—回应—后果”的主线上补出触发它的事件和它后来的回声，通常需要几个段落，而不是一句话。

- 处境：他当时在什么位置，手上有什么资源，被什么限制。
- 事件：触发转折的事情。只写公开材料能支持的部分，不补现场细节。
- 行动：他做了什么、没做什么、说了什么。
- 回应：外界或他人怎样回应；他后来怎样承受、解释，哪些是事后才补充的。
- 后果：生活、工作、关系、债务、迁徙等具体变化。
- 回声：这件事后来怎样进入作品、选择或自我解释。

情绪重量来自具体行动和代价，不靠“巨大的打击”一类形容词。读者应该能看到这件事怎样改变了他之后的路。

敏感转折（亲人离世、疾病、暴力、监禁）只写本人公开讲述、且与公共经历或作品直接相关的部分；不补病因、医院、精确年龄、住址等私人细节。材料只到某一步时，用自然语言说明可知范围（如“他后来没有细说”），详细冲突留在附卷，不用想象填满。若转折在正文里只占一两句，问自己：读者能否理解它为什么重要？不能，就回到材料补行动链和后果，而不是加形容词。

## 正文不是台账

正文是给读者读的故事，不是研究日志。“本轮未取得可读原文”“本文不采用”“公开报道有不同说法，他没有展开”这类句子放附卷的写作说明、矛盾或访问台账；正文只在冲突影响理解时，用自然语言轻轻带过：“关于这一年，公开说法并不一致”“他后来没有细说”。

访问失败、同源组、抓取层级、页码、查询次数不进正文；这些是附卷的职责。不要为了显得严谨，在每段开头堆“本人自述/记者报道/机构记录”；用“他后来回忆”“记者写道”“档案显示”自然归属。

正文里的“不确定”要服务于理解，不是免责声明。能确认的写清楚，不能确认的留白；不要把研究过程当情节，也不要用流畅的叙述掩盖会改变理解的冲突。

## 配图：年代、人物与授权

每个重要年代尽量有一张图，或至少一个明确的图位。图片不是装饰：它让读者看到当时的舞台、街道、村庄、器物，帮助建立年代感。长文章尤其要检查中段和结尾，不能只在开头放图。

优先用本人当时的照片。没有本人照片时，可以用地点或器物图；图注正面写画面本身，例如“甘洛县山村，2023 年”“月琴（博物馆藏品）”“成昆铁路，2019 年”。不要写“这是乐器图，不是他父亲的琴”“这是路线图，不是他乘车时的照片”一类排除句，也不要把作者、许可、来源或“经授权使用”写进图注。读者看画面和文字就能知道它是什么；是否本人在附卷配图表标明，作者、许可与授权在 `CREDITS.md`。节目截图不写成生活照；现代地点图不能冒充旧照。做到这一点靠选图和画面描述，不靠在图注里补“这不是……”。

找不到图时，先检查已保存页面的 `img`、`og:image` 和结构化数据，再尝试公开文章接口、媒体图库和作者授权；不要一句“拿不到”就停。用户已确认授权时，按授权范围取用，并记录授权日期、来源和凭证；如果用户只说已授权、没有说明范围，记录“用户确认授权，范围未提供”，发布前再确认，不要替授权方补范围。CC 图与用户授权照片分列 `CREDITS.md`，不把授权照片当 MIT 内容分发；未成年人或家庭成员照片不采用，确有重大公共利益的材料只在附卷记录，不放进正文。

附卷列“图片缺口”表：场景、需要的图、现有替代、授权状态。读者由此知道哪些年代有图、哪些只是替代图。

## 场景的边界

| 写入正文的内容 | 所需依据与写法 |
|---|---|
| 时间、地点、在场者、动作、物件、可见环境 | 已读材料明确记载；未知部分省略，不能按年代或职业常识补齐 |
| 对白 | 已核原文或字幕、录音位置；直接引语保持原意，转述不用引号，不能把不同时间的话拼成现场对话 |
| 心情、愿望、犹豫、决定理由 | 本人公开文字或回忆，或明确归属的亲历者叙述；“他后来回忆……”与“某人认为……”不能变成全知内心独白 |
| 时代与行业环境 | 有来源的背景材料；不能把一般现象写成此人确实遭遇的事 |
| 因果关系 | 有可核行动链或归属明确的解释；时间先后、两件事相邻和本人事后解释，分别说明 |
| 跨来源重建 | 核对是否同一事件、日期与参与者；可融合相容事实，不能把异时异地细节拼成一次经历 |

完整场景和段落旁保留足以定位相关细节的来源；多源重建在附卷注明对应关系。若只能依据事后回忆，开头自然交代回忆来源与时间，让读者知道叙事视角。

## 让读者跟随行动

- 把抽象履历展开成真实过程：当时想解决什么，手上有什么，采取什么行动，外界怎样回应，结果如何。用材料里的人、物、作品、数字与动作形成画面，不靠形容词代替信息。
- 回到当时可知的范围。写一个尚未出名的人时，不让未来的财富与名声替他解释每一次决定；不用“他还不知道命运的齿轮已经转动”一类预言式句子。
- 展示转折的代价与复杂性。本人想法和他人的观察可以并置，让读者看见分歧；不通过叙述者的道德标签替读者定论。
- 用具体事件推动节奏；相似经历可概述，关键节点放慢。材料少的年月自然过渡，资料密集也不必每条都塞进正文。
- 采用第三人称非虚构叙事。读者进入的是有依据的处境，不扮演当事人，不以“如果我是他”的想象补经历。

## 来源自然进入故事

正文以连续段落和人生章节为主，不逐句加“本人说法/机构记录”标签。可用“他在多年后的访谈中把这次离开归因于……”“同事对此有另一种解释……”自然保留归属；相关句段附编号与来源链接。来源附卷保留类型、获取范围、原始文件与具体定位。

阅读过程、HTTP 错误、哪页未抓到、查询次数放附卷；材料冲突或原件缺失影响理解时，在叙事当处简洁说明，具体边界见“正文不是台账”。

用户要求可发布或可分享时，按可用来源与篇幅整理短引语、概述与引用，保留必要归属，不大段搬运原稿、书籍或字幕。

## 自述归属：生成、改稿与核验

一条结论仅由当事人自述支持时，可以写入故事，但正文须自然保留“他后来回忆”“据他在该次采访中的讲述”等归属。引用编号或来源链接不能替代归属；documented_statement 只表示材料这样记载，不表示经历已独立核验。

先沿现有来源对应核对材料关系。同一原始自述的转载、翻译和转引仍属同源组；没有新增独立证据时，来源数量增加不得成为删去归属或升级结论状态的理由。独立性未知就保留缺口，不凭不同网址推定相互印证，也不自行扩展调查。

缩写、润色和段落重排后，逐项检查自述归属是否仍明确覆盖对应结论。可在段首先交代回忆者与来源，再连续叙述；不要求逐句重复标签。但跨段、换说话人或重排后覆盖不清时，恢复必要归属。不得把带归属的个人解释改成叙述者确认的因果。

核验时对照具体材料及定位，既查无归属的直接断言，也查“附有链接却把自述写成事实”的句段。报告问题位置、材料依据、影响及最小修正；自然同义表达或覆盖清楚的段首归属不算缺失。只有链接、固定词命中或台账脚本通过，都不能代替此项语义核对。新出现独立证据或争议时沿用既有证据规则，不自动删除归属。

## 审稿：双重验收

**代入感检查：** 读者能否说清这一阶段他身处什么环境、想要什么、实际做了什么、经历了什么回应或代价，及后续怎样变化？正文应包含已读材料的具体内容，不停留在履历清单和“访谈谈到了什么”。同时检查：读者能否说出他当时多大、本名/公开名、这一阶段长什么样；重大转折是否只有一句；正文有没有混入台账语言。

**事实检查：** 逐场景检查时间、主体、动作、对白、感受和因果是否都有对应依据。核对录制/发表日期、同一事件的前后阶段、引语语境及说话人。没有来源的细节删去或回到搜索；不能用“这是文学化表达”豁免事实要求。

两项相互配合：事实充分但叙述像资料卡时，继续消化材料与组织段落；叙述精彩却出现无据细节时，回到证据修正。材料确有空白就诚实保留，不设固定字数、固定场景数量或戏剧性要求。
