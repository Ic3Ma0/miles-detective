# R005 刘慈欣：公开人生调查案例

这是一份完整的 `miles-detective` 案例：从 1963 年出生追到 2026 年 10 月，把公开材料写成一篇有出处的人生故事，并附上可逐条核对的研究台账。

它不是人物百科，也不是二手改写。正文里的每个场景、引语和转折都能回到来源目录；查不到的地方留白，两种并存的记忆并列保留。

## 先读什么

1. [人生故事正文](outputs/R005_刘慈欣_人生故事.md)：6,600 余字，十个章节，80 处来源编号。
2. [资料附卷](outputs/R005_刘慈欣_资料附卷.md)：时间线、来源目录、矛盾表、覆盖与未解队列、下一轮查询计划。
3. [记录摘要](outputs/R005_记录摘要.md)：由 `records.jsonl` 生成的来源表与事件时间线。
4. [案例展示稿](outputs/R005_案例展示稿.md)：如需放进 README 或案例页，可直接取用。

## 这个案例展示了什么

- **早年材料追到本人自述**：1970 年罗山村庄看东方红一号、1975 年驻马店洪水、第一次理解“光年”时的“吸毒般的快乐”，都来自《三体》英文版后记，而不是二手转述。
- **身份消歧**：水木清华 BBS 的 `nzg（lcx）`、新浪博客 `workership` 都能找到原始载体；本人长期不用微博微信；网传贴吧账号因无原始证据被列为未解线索，不予采用。
- **独立来源判定**：2015 年雨果奖用央视、环球人物、新闻晨报三组独立采访交叉核对；同一篇专访的多个转载只算一组。
- **矛盾保留**：读《2001》有 1980 年冬与 1981 年高考后两说；毕业年份有 1985 与 1988 两说；同事发现他写作有两个版本——都并列保留，不静默选一个。
- **受阻记录**：《人物》2015 年封面报道被知乎反爬拦截，正文未读，只登记目录页，不用其细节下结论；水木 SF 板原帖随论坛关停，现存他人转帖，标明“转帖不能证明原帖未改”。

## 台账说明

`records.jsonl` 保留 186 条记录：18 个检索、36 次访问、36 个来源、40 条结论、37 个事件、9 条线索、10 条覆盖。为控制体积与版权风险，本目录**不包含原始页面抓取**；检索与访问记录中的 `raw_path` 指向本目录内的 `search-log.md` 与 `visit-log.md`，原始文件保留在作者本地研究目录。

`records.jsonl` 可用技能自带脚本做结构检查：

```bash
python3 ../../scripts/research_log.py check .
```

## 已知限制

- 《人物》2015 年第 10 期封面报道《刘慈欣：装在格子衬衫里的人》只有目录页，正文被反爬拦截，未读全文。
- 水木清华“科学幻想”版原帖随论坛关停，本轮只取得一篇 2003 年转帖。
- 本轮未启用 Wayback/Common Crawl，也未系统检索 CNKI；2016—2022 年长篇访谈未穷尽。
- 读《2001》的时间、大学毕业年份、同事发现他写作的版本存在两种以上说法，正文与附卷均并列保留。
